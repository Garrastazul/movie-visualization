# Visualización UpSet de Géneros Cinematográficos

Este repositorio contiene el código y la visualización en formato **UpSet Plot** desarrollada para analizar las relaciones e intersecciones entre los diferentes géneros cinematográficos.

![Visualización UpSet de Géneros Cinematográficos](upset_generos.png)

## 📌 Descripción del Proyecto
El objetivo de este proyecto es desglosar la superposición de géneros en la industria del cine utilizando un enfoque matricial escalable. A diferencia de los diagramas de Venn tradicionales, esta técnica permite observar con claridad tanto el volumen total de cada género como las combinaciones complejas (intersecciones multietiqueta) más frecuentes.

---

## 📊 Fuente de Datos y Metodología
* **Fuente de datos:** TMDB Raw Movie Dataset (2010–2025).
* **Referencia:** Christiawan, E. (2026). *Zenodo*. [doi:10.5281/zenodo.21920642](https://doi.org/10.5281/zenodo.21920642)
* **Técnica empleada:** UpSet Plot (*Visualizing Intersecting Sets*).

---

## 💡 Insights Principales
* **Prevalencia de géneros individuales:** *Drama* y *Comedy* son los géneros con mayor volumen de producciones absolutas.
* **Intersecciones destacadas:** La combinación doble de *Drama + Comedy* lidera ampliamente las producciones multietiqueta.
* **Hibridación:** Las combinaciones dobles y triples concentran la mayor parte del catálogo frente a mezclas de más de cuatro géneros.
